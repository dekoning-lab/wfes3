# Phase Type Distribution

## Description

Phase Type Distribution computes the distribution of the time between successive
fixations, treating extinction as transient so the allele can be regenerated by
mutation. The time to absorption in the resulting single-absorbing-state model
is the time to the next substitution, and it has a discrete phase-type
distribution, which is what makes the whole distribution computable rather than
only its moments.

The shape of that distribution has a direct consequence for phylogenetics.
Markovian models of sequence evolution assume substitution times are
geometrically (or exponentially) distributed, as memorylessness requires. The
distributions computed here resemble a geometric distribution preceded by a
substantial probabilistic delay, which means substitution times under the
Wright-Fisher model are not Markovian but semi-Markovian. The rate reported is
also a finite-sites quantity, which is the rate that models of phylogenetic
sequence evolution actually require.

## Mathematical Model

The time to substitution follows a phase-type distribution where only fixation (i = 2N) is absorbing.

### Substitution Time Distribution

With extinction as a transient state, the generator matrix Q includes transitions from i = 0:
$$T_{sub} \sim \mathrm{PH}(\alpha, Q)$$

Where:
- α: Initial distribution (typically starting from 0 with mutation)
- Q: Generator matrix with fixation removed

### Probability Density Function

$$f_{sub}(t) = \alpha \, e^{Qt} (-Q) \, e_{fix}$$

### Cumulative Distribution Function

$$F_{sub}(t) = 1 - \alpha \, e^{Qt} \mathbf{1}$$

### Key Statistics

From the phase-type distribution:
- Mean: E[T_sub] = -α × Q^(-1) × 1
- Variance: Var[T_sub] = 2α × Q^(-2) × 1 - (E[T_sub])²
- Substitution rate: μ_sub = 1/E[T_sub]

## Input Parameters

### Required Parameters
- `-N, --pop-size <int>`: Population size

### Model Parameters
- `-s, --selection <float>`: Selection coefficient (default: 0)
- `-h, --dominance <float>`: Dominance coefficient (default: 0.5)
- `-u, --backward-mu <float>`: Backward mutation rate (default: 1e-9)
- `-v, --forward-mu <float>`: Forward mutation rate (default: 1e-9)

### Distribution Parameters
- `-a, --alpha <float>`: Transition-matrix tail truncation (default: 1e-20). Each
  row of the matrix is a binomial distribution over offspring allele counts;
  alpha is the total probability mass trimmed from that row's two tails, alpha/2
  from each, after which the row is renormalised to sum to 1. It is a quantile
  cut rather than a floor on individual entries -- at the default, stored entries
  as small as 1e-43 remain. Raising it makes the matrix sparser and the solve
  faster while discarding real probability mass; values much above 1e-3 are
  refused unless `--force` is given. At the 1e-20 default this is not a no-op: for N=100 it stores 23,015 of the 39,601 entries a fully dense row set would hold, discarding 42% of the entries while removing at most 1e-20 of the mass from each row.
- `-i, --initial <path>`: Initial state distribution, as a CSV column of 2N probabilities over allele counts 0..2N-1 in the fixation-only model. It replaces however the starting state would otherwise be set -- a fixed count, or the integration over the copy numbers a new mutation produces -- and is renormalised if it does not sum to 1. A point mass reproduces the corresponding fixed-count run exactly.

  (Not to be confused with the alpha in the phase-type equations above,
  which is the initial state probability vector.)
- `-c, --distribution-cutoff <float>`: Stop when CDF reaches this value (default: 0.99999)
- `-t, --max-t <int>`: Maximum time to compute (default: 1000000)

### Computational Parameters
- `--sampling-frequency <int>`: Sample every nth time point for output (default: 1)
- `--num-threads <int>`: Number of threads
- `--force`: Skip parameter validation
- `--library <string>`: Linear algebra backend: `Pardiso` (Intel MKL; the default on Linux), `Accelerate` (the macOS default), `SuiteSparse`, or `ParU` (parallel SuiteSparse). Note that on macOS `Accelerate` names the matrix backend only: matrices are held in Accelerate format, but the LU factorization and solves are performed by SuiteSparse's UMFPACK. Apple's own sparse solver is used only as a build-time fallback when SuiteSparse is not linked. ViennaCL requires OpenCL support not compiled into the shipped binaries.

### Output Options
- `--output-Q <file>`: Write generator matrix
- `--output-R <file>`: Write absorption rates
- `--output-P <file>`: Write distribution to file

## Output Format

### Standard Output (CSV)
```
time,P(t),CDF
0,0,0
1,1.2e-5,1.2e-5
2,2.3e-5,3.5e-5
3,3.4e-5,6.9e-5
...
```

### With Sampling Frequency
If `--sampling-frequency 100` is specified, only every 100th time point is output, reducing file size while maintaining distribution shape.

### Summary Statistics (stderr)
```
Mean substitution time: 125000
Std dev: 35000
Substitution rate: 8e-06
Total probability computed: 0.99999
Execution time: 8.5s
```

## Usage Examples

### Basic substitution distribution
```bash
phase_type_dist -N 1000 -s 0.01
```

### Neutral substitutions with mutation
```bash
phase_type_dist -N 10000 -u 1e-8 -v 1e-8
```

### Nearly neutral with sampling
```bash
phase_type_dist -N 5000 -s 0.001 -h 0.2 --sampling-frequency 1000
```

### Extended time range
```bash
phase_type_dist -N 1000 -s 0.0001 -t 100000000 -c 0.999999
```

### Output to file with matrices
```bash
phase_type_dist -N 500 -s 0.01 --output-P dist.csv --output-Q gen.csv
```

## Technical Notes

1. **Non-Absorbing Extinction**: Key difference from standard time distributions
2. **Automatic Starting**: Typically starts from 0 copies with mutation
3. **Matrix Exponential**: Computed using uniformization and scaling methods
4. **Sampling**: Reduces output size for long distributions
5. **Numerical Stability**: High precision for rare events and long times

## Biological Interpretation

This model represents:
- **Substitution Process**: Complete cycle from mutation to fixation
- **Molecular Clock**: Time between fixed differences
- **Neutral Theory**: At s=0, rate equals forward mutation rate
- **Nearly Neutral**: Effects of weak selection on substitution times

## Comparison with Related Programs

- **time_dist**: Both extinction and fixation absorbing
- **phase_type_dist**: Only fixation absorbing (substitution focus)
- **phase_type_moments**: Fast moment calculation without full distribution
- **time_dist_dual**: Includes initial mutation waiting time

## Applications

The substitution-time distribution is the waiting-time distribution between
successive fixations under ongoing mutation pressure, which is the quantity behind
molecular-clock calculations. Its mean sets the expected substitution rate, and its
variance sets how much rate variation follows from the population process alone,
before any variation in mutation rate or selection is invoked.

For the moments by themselves, phase_type_moments computes them directly and
without the truncation that this program's finite time horizon imposes.
